## 2. The description standard (owner-approved, enforced in code)

The owner picked the **Calvin Klein Eternity** product page as the format for every
product:

```html
<p><strong>{Product name}</strong> {2-3 sentences in our own words: scent character,
who it suits, a few key notes}</p><ul>
<li><strong>Top notes:</strong> a, b, c</li>
<li><strong>Heart notes:</strong> a, b, c</li>
<li><strong>Base notes:</strong> a, b, c</li>
<li><strong>Scent family:</strong> e.g. aromatic fougère</li>
<li><strong>Best for:</strong> e.g. office, everyday wear, spring and summer</li>
<li><strong>Concentration:</strong> one fixed line, below</li>
</ul>
```

**Concentration lines** (use exactly one):
- "Eau de Parfum: richer and longer-lasting than an Eau de Toilette"
- "Eau de Toilette: lighter and fresh, easy to wear every day"
- "Extrait de Parfum: the most concentrated and longest-lasting form"
- "Parfum: highly concentrated and long-lasting"
- "Eau de Cologne: light and refreshing"
- "Concentrated Perfume Oil: alcohol-free and applied directly to the skin" (oils only)

**Rules:**
- **Length:** 70–110 words. **Nothing after the list.** The old line "100% authentic.
  Ships from our warehouse in Oakville…" was removed everywhere, because the owner
  dislikes it.
- **Own words, never copied** from websites. Notes are facts; the sentences must be
  ours.
- **Notes need at least two agreeing sources, or the brand's own page.** Never write
  notes from memory. Never sort a flat note list into top/heart/base yourself.
- **We are a retailer.** Third person only, never "our perfume" or "we created".
- **Wording:**
  - Never name another brand or designer in a product's text.
  - No "clone / dupe / twist / knock-off / inspired".
  - Impression-style products (most Arabian houses, American Impression) are fine to
    sell. Describe their own scent.
  - No prices or sizes. Canadian spelling.
- **Testers:** end the paragraph with "Tester: the same fragrance in plain packaging,
  may come without a cap."
- **When to skip (leave the product hidden):** notes conflict, the title doesn't
  identify the fragrance or version, the variants mix different perfumes, or it isn't
  a perfume.

**Code gate:** `bw/descriptions.py` enforces all of this, with tests in
`tests/test_descriptions.py` (all pass).
- `problems(html)` rejects:
  - empty text
  - "???"
  - fancy Unicode
  - garbled encoding (Ã, â€)
  - pasted links, spans or styles
  - the maker's voice
  - clone/dupe wording
  - more than 120 words
- `standard_problems(html)` also checks the exact house format.
- The listing builder and the CSV exporter call `require_clean`.
- `python -m bw.cli audit-descriptions <bulk.jsonl> --active-only` scans the store.

**Gate command** to run before every description write:
```
cd /home/user/i-am-pog && python3 -c "import sys,json;from bw.descriptions import standard_problems;d=json.load(open(sys.argv[1]));print({k:standard_problems(v) for k,v in d.items() if standard_problems(v)})" descs.json
```

## 7. How to work (what worked, what bit us)

- **Big exports:** use `bulkOperationRunQuery`. Poll `node(id){... on BulkOperation{status url}}`,
  then `curl` the JSONL. Only one bulk query runs at a time per shop.
- **Bulk mutations** (`bulkOperationRunMutation`) are blocked. Use aliased mutations
  instead, 15–25 per request, with variables built by Python from a file.
- **Hiding products:** `bulk-update-product-status` handles about 30 products before it
  hits a 60-second timeout. After a timeout, re-check with a `nodes` query before
  retrying.
- **Stock:** `inventorySetQuantities` needs `changeFromQuantity: null` on each item and
  an `@idempotent(key:"…")` directive, with name "available". Location
  `gid://shopify/Location/52596932776` (Oakville Warehouse).
- **New products:** use `productSet` (synchronous) to create, then `publishablePublish`
  to the Online Store (`gid://shopify/Publication/56528306344`), Shop and Google.
- **Descriptions are researched by background agents**, two per round of about 95
  products each.
  - WebSearch allows about 200 searches per user message in total, so give each agent
    about 95.
  - Agents run out of context after about 20 large batches. Have them log progress to a
    `*_done.jsonl` file so they can resume.
  - Container restarts stop agents. Resume them by sending a message to their id.
- **`clean_money()` bug:** in `bw/suppliers/base.py` it reads "$1,280" as 1.28 and is
  **still unfixed**; there's a suggested task for it. Parse Ace money with
  `re.sub(r'[^0-9.]','',x)` instead.
- **Admin links:** `https://admin.shopify.com/store/shopbrandswarehouse/products/{id}`.
  Storefront: `brandswarehouse.com`.
